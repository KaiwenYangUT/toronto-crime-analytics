# RESULTS

The registry of every output file whose numbers may appear on the site or in the paper (AGENTS.md rule 3).
- `results/index.json` is the machine-readable version. This file is generated from it, plus a short description per entry.
- A number that isn't traceable to a key below must not be published.

Each results file carries a provenance header: `{producer, git_sha, inputs: {file: sha256}, seed, created}`.
