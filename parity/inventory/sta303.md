## Caveats and handoff to P2 / later parity

The legacy frame's missingness-based exclusions and wider dates are parity facts, not the unified task definition. No result supports place/time robbery risk, safety, or causality.
2. **Post-2019 is a period indicator:** source name `Covid_Outbreak` and narrative “Year” are misleading. It includes all later trends/reporting changes; retain original legacy term identity and flag wording until the improvement phase.
3. **Frame selection:** complete cases on unused fields can exclude observations for reasons unrelated to time predictors. Geography is not actually modelled. Preserve row order and report category/NA drops before introducing explicit unified rules.
4. **Numeric time and collinearity:** hour/day/month linear effects, season derived from month, fixed nighttime cutoffs and main effects only; no circularity or date-specific light measurement. The VIF prose says moderate multicollinearity but source outputs must determine whether its specific numbers/messages agree.

The note flags dense diagnostic plots as hard to read (note line 78); preserve original chart types before any approved improvement.
